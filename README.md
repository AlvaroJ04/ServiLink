# ServiLink - Frontend

Frontend de la plataforma de contratación de servicios técnicos "ServiLink".
Desarrollado para cumplir con las Historias de Usuario del **Sprint 1: Fundaciones y Autenticación**.

## 🛠️ Tecnologías Utilizadas
Este proyecto está construido con un stack moderno enfocado en rendimiento y escalabilidad:
- **React** con **TypeScript**
- **Vite** (Empaquetador y servidor local de alta velocidad)
- **React Router DOM** (Gestor de navegación y protección de rutas privadas - RBAC)
- **ESLint** (Linter para mantener el estándar y calidad del código)

## 📋 Requisitos Previos
Para que cualquier desarrollador del equipo pueda correr este proyecto localmente, es obligatorio tener instalados los siguientes programas:

1. **Node.js**: Descargar e instalar desde [nodejs.org](https://nodejs.org/).
2. **pnpm**: Utilizamos `pnpm` como gestor de paquetes en lugar del `npm` tradicional porque es más rápido y eficiente. 
   - Una vez instalado Node.js, abre una terminal (PowerShell o CMD) y ejecuta: 
     `npm install -g pnpm`
